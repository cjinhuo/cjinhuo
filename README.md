### Hey, I'm [Shanks](https://cjinhuo.netlify.app/). 👋

Here are some open-source tools I build and work on:

- 🔍 **Text Search Engine:** JavaScript fuzzy search for Chinese, Pinyin initials, and English. Try the [interactive demo](https://cjinhuo.github.io/text-search-engine/) or read the [English quickstart and library comparison](https://cjinhuo.github.io/text-search-engine/en/) / [中文指南](https://cjinhuo.github.io/text-search-engine/guide/).
- ⚒️ **Blazwitcher:** Find browser tabs, bookmarks, and history by Pinyin; use AI to group tabs in the browser extension. [Product demo](https://blazwitcher.vercel.app/en) · [Chrome Web Store](https://chromewebstore.google.com/detail/fjgablnemienkegdnbihhemebmmonihg).
- 📟 **Morse Typer:** [Practice Morse code](https://cjinhuo.github.io/morse/) with a keyboard, or [convert text to Morse code](https://cjinhuo.github.io/morse/converter/).
- ⌨️ **Schema Studio:** [Convert Apache Thrift to JSON Schema online](https://cjinhuo.github.io/thrift-to-json-schema/) and validate sample JSON.
- 🎉 **MitoJS:** Web and Mini Program monitoring SDK. See the [SDK guide](https://mitojs.github.io/mito-doc/sdk/guide/introduction/), [React](https://mitojs.github.io/react-sdk-demo/), [Vue 2](https://mitojs.github.io/vue2-sdk-demo/), and [Vue 3](https://mitojs.github.io/vue3-sdk-demo/) demos, or explore the [dashboard with sample data](https://mitojs.github.io/mito-admin-demo/).
- 📦 **Monorepo tooling:** [Starter scripts](https://github.com/cjinhuo/mono-sdk-boilerplate) for pnpm, Changesets, and Nx.

💬 [Ask me about these projects](https://github.com/cjinhuo/cjinhuo/issues).
